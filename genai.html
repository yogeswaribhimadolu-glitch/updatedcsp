Generative AI, AI agents and agentic AI

These three terms are often mixed up. This page explains each one in depth, shows how they connect, and ends with a comparison table and a quiz. The short version: Generative AI creates, AI agents act, and agentic AI plans and pursues goals on its own.

The big picture

1. Generative AI

Creates new content such as text, images, audio, video and code from your prompt.

2. AI agent

Uses an AI model plus tools to complete a specific task for you, such as checking an order or booking a meeting.

3. Agentic AI

Pursues a bigger goal on its own: it plans, acts, checks, and adjusts, often with several agents working together.

Easy way to remember: Generative AI is a talented writer. An AI agent is an assistant who can also run errands. Agentic AI is a project manager who plans the whole project and keeps going until it is done. Each level is built on top of the one before it.

Generative AI

Generative AI is AI that produces new content instead of only analysing existing data. You give it a prompt, and it generates a response. It answers one request at a time and does not act in the outside world by itself.

How it works

  1. Train on huge amounts of dataA model reads enormous collections of text, images, audio or code. It does not store them like a database. It learns the patterns inside them.
  2. Learn the patternsA language model learns which tokens are likely to follow other tokens. An image model learns how shapes, colours and styles relate to descriptions.
  3. Generate from your promptA language model writes one token at a time, each time predicting the most likely next one. Many image models (diffusion models) start from random noise and remove the noise step by step until a picture that matches your text appears.

What it can create

Text

Essays, summaries, emails, explanations, translations and stories.

ExamplesChatGPT, Claude, Gemini

Images

Photos, illustrations, posters and logos from a written description.

ExamplesMidjourney, DALL·E, Adobe Firefly

Audio and music

Natural voices, voice dubbing, sound effects and full songs.

ExamplesElevenLabs, Suno, Udio

Video

Short clips from text, AI presenters and translated videos.

ExamplesSora, Runway, Veo

Code

Functions, whole apps, bug explanations and test cases.

ExamplesGitHub Copilot, Cursor

Strengths and limits

Strengths

  • Very fast first drafts of almost any content
  • Explains difficult topics in simple language
  • Works across text, images, audio and code
  • Available to anyone through simple chat tools

Limits

  • Can make up facts (hallucinations)
  • Can repeat biases from its training data
  • Only knows what it was trained on unless it has search
  • Does not take actions in apps or the real world by itself

AI agents

An AI agent is a system built around an AI model that can use tools to complete a task. Where a plain chatbot only replies with text, an agent can also do things: search the web, read a database, run code, send an email or update a calendar.

The four parts of an agent

Model (the brain)

A language model that understands the request, decides what to do next and writes the result.

Tools (the hands)

Functions the agent is allowed to call: web search, calculator, email, calendar, code runner, company database.

Memory

Short-term memory holds the current task and results so far. Some agents also keep long-term notes such as your preferences.

Instructions and goal

The task from the user and the rules from the developer, such as what the agent may and may not do.

Example: a customer support agent

  1. Understand the requestThe customer writes: "Where is my order 4821?"
  2. Choose and call a toolThe agent calls the order database tool with the order number.
  3. Read the resultThe tool returns: shipped yesterday, arriving Friday.
  4. Reply and offer more helpThe agent tells the customer the delivery date and offers to send a tracking link.

More real examples

Coding agent

Reads your project files, runs the tests, finds a failing test and edits the code to fix it.

Scheduling agent

Checks calendars, finds a free time for everyone and sends the meeting invite.

Research agent

Searches many web pages, collects the important facts and writes a summary with sources.

Limits: An agent can pick the wrong tool or misread a result. That is why agents are usually given limited permissions and a defined task.

Agentic AI

Agentic AI describes systems that work toward a larger goal with a high degree of independence. Instead of following one task, they break a goal into sub-goals, decide the steps, use tools, check their own results and change the plan when something goes wrong. Often several specialised agents work together.

What makes a system agentic

Goal-driven

You give an outcome ("prepare my trip"), not step-by-step instructions.

Multi-step planning

It creates a plan and orders the steps itself.

Teamwork

A planner agent can hand parts of the work to specialist agents.

Self-correction

It checks results and retries or re-plans if a step fails.

Long-running

It can keep working, or keep watching for changes, over minutes, hours or days.

Human in the loop

It asks for approval before risky steps such as payments.

Example: an agentic trip planner

  1. GoalYou say: "Plan a 3-day trip to Chennai under 8,000 rupees for me and a friend."
  2. PlanA planner agent splits the goal into transport, stay, food and budget.
  3. Specialist workSeparate agents search trains, compare hotels and suggest places to visit.
  4. CheckA checking agent adds up the cost. It is over budget, so the plan is adjusted to a cheaper hotel.
  5. MonitorAfter booking, the system watches for delays. If the train is cancelled, it finds another option.
  6. Human approvalBefore any payment is made, it asks you to confirm.

The autonomy scale

Chatbot

Answers questions. You do everything else.

Assistant with tools

Can look things up or run one action when you ask.

AI agent

Completes a defined task using several tool calls.

Agentic system

Plans, acts, checks and adapts across many steps to reach a goal.

Risks and safeguards

Risks

  • A small early mistake can grow through many steps
  • Wrong actions can cost money or send wrong messages
  • Agents that read web pages can be tricked by hidden instructions (prompt injection)

Safeguards

  • Human approval for important actions
  • Limited permissions for each tool
  • Logs of every step so people can review
  • A stop button and thorough testing
