How AI reads: tokens and context windows

AI models don't read words like we do. They read small pieces called tokens, and they can only remember a limited number of them at a time. Understanding these two ideas explains most of how tools like ChatGPT, Claude and Gemini behave.

What is a token?

A token is the smallest piece of text an AI model reads and writes. It can be a whole word, a part of a word, a number, a space, or a punctuation mark. Models do not see letters or words the way we do. They only see a sequence of tokens.

Common words

Short, everyday words are usually one token. "cat", " the" and "AI" are each 1 token, and the space before a word is often part of the token.

Long or rare words

Longer or rarer words are split into parts. "Unbelievable" may become "Un" + "believ" + "able", which is 3 tokens.

Numbers, symbols, code

Numbers, punctuation, emojis and code symbols also become tokens. Code and numbers often use more tokens than plain English of the same length.

How text becomes tokens

A program called a tokenizer sits in front of the model. Here is what happens every time you send a message.

  1. SplitThe tokenizer cuts your text into pieces using a fixed list of known pieces, called the vocabulary. Vocabularies usually contain tens of thousands to a couple of hundred thousand pieces.
  2. Convert to numbersEvery piece has an ID number in the vocabulary. Your sentence becomes a list of numbers, because neural networks work only with numbers.
  3. Predict the next tokenThe model reads all the token numbers and predicts the most likely next token. It repeats this again and again, one token at a time, to build the answer.
  4. Convert back to textThe generated token numbers are turned back into words and shown to you.

Where does the vocabulary come from?

Most tokenizers use a method called byte pair encoding (BPE). It starts with single characters and looks through a huge amount of text. It finds the pair of neighbouring pieces that appears most often, for example "t" and "h", and merges them into one new piece "th". It repeats this thousands of times. In the end, very common words become single tokens, while rare words are built from smaller parts.

Why tokens matter

They set the limits

Everything a model can handle at once is measured in tokens, not words or pages. Your prompt, the chat history and the answer all share the same token limit.

They decide the cost

Companies that offer AI through an API usually charge per token, with separate prices for the tokens you send (input) and the tokens the model writes (output). Longer prompts and answers cost more.

They affect speed

The model writes one token at a time, so a longer answer takes longer to appear. Very long inputs also take more time to process.

They explain odd mistakes

Because models see tokens and not individual letters, tasks like counting the letters in a word or spelling backwards can be harder for them than you would expect.

What is a context window?

The context window is the maximum number of tokens a model can look at in one go. Think of it as the model's desk. Everything it needs to work with must fit on the desk. Once the desk is full, something has to be removed.

What fills the window?

The window is not only your latest question. It holds all of these together:

Rules Chat history Files you add Reply

Inputs

  • Hidden rules: instructions from the app maker (the system prompt)
  • Chat history: every earlier message from you and the AI
  • Files and pasted text: PDFs, documents, code
  • Tool results: web pages or data an agent fetched

Output

  • The model's answer also uses tokens from the same window
  • If the input takes almost all of the window, there is little room left for a long answer

What happens when the window is full?

Old parts are dropped

Many chat apps quietly remove or shorten the oldest messages to make room. That is why an AI can "forget" something you said at the start of a very long chat.

You get an error

Some tools simply refuse and tell you the input is too long. You then need to shorten the text or split it into parts.

Details get lost in the middle

Even when everything fits, models can pay less attention to information buried in the middle of a very long input. A bigger window is not the same as perfect memory.

Context is not permanent memory. The model does not learn from your chat forever. When you start a new chat, the window starts empty again, unless the app has a separate memory feature that saves notes for you.

Tips for using tokens and context well

Be clear and short

Remove filler words and repeated instructions. Fewer tokens means lower cost and more room for the answer.

Start a new chat for a new topic

Old, unrelated messages still fill the window and can distract the model.

Paste only what is needed

Instead of a full 100-page PDF, paste the two chapters that matter.

Put key facts near the end

For long inputs, repeat the most important instruction or question at the end.

Summarise long chats

Ask the AI for a short summary and start a new chat with that summary.

Check your language

Text in some languages needs more tokens. Keep this in mind for limits and costs.

Frequently asked questions

Is a token the same as a word?

No. A token can be a whole word, part of a word, or a symbol. On average one English word is about 1.3 tokens.

Why do different AI tools count different numbers of tokens for the same text?

Each model family uses its own tokenizer and vocabulary, so the same sentence can be split in different ways.

Does the AI's answer use up the context window too?

Yes. The window has to hold your input and the model's output together.

Is a bigger context window always better?

Not always. Long inputs cost more, take longer, and can hide details in the middle. Use only as much context as the task needs.

Why do languages like Telugu often use more tokens?

Tokenizers are often trained mostly on English text, so less common scripts get cut into many small pieces. Newer tokenizers have improved this, but some languages can still cost more tokens for the same meaning.
